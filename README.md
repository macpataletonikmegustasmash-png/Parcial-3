1. Título del proyecto
ReparaTec

2. Descripción
En muchas comunidades existen estudiantes, adultos mayores y familias que no cuentan con una computadora, tableta o teléfono celular para realizar actividades educativas, laborales o personales. Al mismo tiempo, empresas, instituciones y ciudadanos desechan equipos electrónicos que todavía podrían repararse y reutilizarse. Se propone desarrollar ReparaTec, una plataforma que permita registrar equipos tecnológicos donados, administrar sus diagnósticos, controlar las reparaciones y asignarlos a personas o instituciones que los necesiten.

3. Tecnologías utilizadas
Lenguajes: HTML5: Utilizado para la estructura y maquetación web semántica.

CSS3: Implementado para el diseño visual.

JavaScript (Vanilla JS / ES6+).

Markdown: Utilizado para la documentación técnica y organización del repositorio mediante archivos README.md.

4. Requisitos previos
Herramientas de Desarrollo y Entorno:

Visual Studio Code (VS Code): Editor principal de código fuente para la edición HTML/CSS/JS y previsualización del sitio.

Git y GitHub: Control de versiones y plataforma de alojamiento para gestionar la estructura de carpetas y compartir el código del repositorio.

Navegador web moderno.

5. Instalación
Extensión para instalar: Live Server.

Instalacion de Git: Desde la página oficial (https://github.com/macpataletonikmegustasmash-png/Parcial-3).

6. Uso
Abre el archivo index.html en tu navegador

Características
Estructura semántica de HTML5: Uso constante de etiquetas semánticas como <nav>, <aside>, <header>, <main>, <article>, <section> y <footer>.

Elementos multimedia e interactividad: Inicio de sesión, visibilidad de datos pre-grabados.

Consistencia de marca e identidad: Uso recurrente del pie de página (footer) con datos institucionales de contacto (correo electrónico, teléfono y dirección) e hipervínculos hacia recursos visuales y hojas de estilo compartidas.
